Export remote job data to CSV, JSON or SQLite — in one command

Pull a normalized dataset of remote jobs from 5 boards (Remotive, RemoteOK, Jobicy, We Work Remotely, Hacker News) into a spreadsheet, a database, or your own pipeline. No scraping, no API key, no dependencies.

pip install remote-jobs-export

What you get

One API normalizes 5 remote-job boards into a single clean schema. The remote-jobs-export tool pulls that data locally so you can work with it offline — a CSV to open in Excel/Google Sheets, a SQLite file for SQL, or a JSON feed for your own code.

Stdlib-only (no deps) No API key (free tier) 5 boards, one schema CSV · JSON · SQLite

Install & run

pip install remote-jobs-export

# Snapshot 100 jobs to a CSV (no key needed)
remote-jobs-export --limit 100 -o jobs.csv

# To SQLite for SQL analysis
remote-jobs-export --limit 200 -o jobs.db

# To JSON for your own pipeline
remote-jobs-export --limit 200 -o jobs.json

# One-line summary (counts by source / category / location)
remote-jobs-export --limit 300 --summary

Or run it straight from the repo without installing:

python -m remote_jobs_export.cli --help

Filter your export

# Only Remotive
remote-jobs-export --source remotive -o remotive.csv

# Filter by skills
remote-jobs-export --skills python,devops -o python_devops.csv

# Only high-score (quality) listings
remote-jobs-export --min-score 70 -o top.csv

The normalized schema

Every record is the same shape regardless of source board, which is what makes cross-board analysis practical:

FieldMeaning
titleJob title
companyCompany name
locationRemote / location label
categoryJob category
skillsRequired skills
salarySalary range (when listed)
sourceOrigin board (remotive / remoteok / jobicy / wwr / hn)
publishedCanonical ISO-8601 UTC date (or blank)
urlLink to the original listing

Where the data comes from

The tool reads the Remote Jobs API, which aggregates 5 boards into one endpoint. The free tier is keyless, so a first export works with no setup at all. If you want the raw API (JSON, no local export step), see remote-jobs-api.tten.no.

Related tools in the same product line:

  • Remote Jobs API — the live normalized feed (JSON) behind this exporter.
  • jobfeed-watchdog — a GitHub Action that alerts when a job feed silently breaks or its schema changes.
  • GigWatch — monitoring + digest alerts on top of job feeds.

Use cases

  • Recruiters / talent mapping: build a snapshot of a niche (e.g. "remote Python devops roles") and trend it over time.
  • Data analysts: load remote-job data into SQLite and run your own GROUP BY source / salary analysis.
  • Researchers: a reproducible, dated sample of the remote-job market for a specific day.
  • Automation: feed a JSON export into your own pipeline or dashboard.
