The short list (no-auth sources that work today)

Most "job data" is gated behind an API key, a paywall, or an enterprise sales call. These are the free, keyless sources that returned real data when we tested them on 2026-10-01:

SourceAuthWhat you getChecked
Remote Jobs API None Normalized JSON feed across 5 boards (Remotive, RemoteOK, Jobicy, WWR, Hacker News) — 329 live listings HTTP 200
Remotive API None Raw remote jobs JSON (the source behind the feed's Remotive board) HTTP 200
RemoteOK API None RemoteOK listings JSON (the source behind the feed's RemoteOK board) HTTP 200

Why only three? The other common "free" job feeds either require an API key (e.g. the GitHub Jobs endpoint is now 404/removed) or return stale/empty data. The Remote Jobs API is the only one that aggregates all five boards into a single clean schema for free, which is why it's the default for the exporter below.

Get it as a real dataset (CSV / JSON / SQLite)

The cleanest way to turn any of these into something you can analyze is a one-command export. remote-jobs-export is stdlib-only, no key needed, and reads the Remote Jobs API:

# 200 jobs to a CSV (open in Excel / Google Sheets)
pip install remote-jobs-export
remote-jobs-export --limit 200 -o remote_jobs.csv

# to SQLite for SQL analysis
remote-jobs-export --limit 200 -o remote_jobs.db

# to JSON for your own pipeline
remote-jobs-export --limit 200 -o remote_jobs.json

# filter: only Python roles, or only from one board
remote-jobs-export --skills python -o python.csv
remote-jobs-export --source remoteok -o remoteok.csv

Or skip the tool and hit the keyless feed directly:

curl -s "https://remote-jobs-api.tten.no/v1/jobs?limit=500" \
  | python3 -c "import sys,json; [print(j['title'],'|',j['company']) for j in json.load(sys.stdin)['jobs']]"
